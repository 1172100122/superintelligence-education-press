# SIEP · 智教版

**超级智能教育出版社 · Superintelligence Education Press**

这里收录用 AI 制作的教育动画。从一个值得琢磨的问题出发，用画面和解说，一步步展开思考。可以在网页里观看，也可以下载影片离线观看。

## 第一部：差一点，还是等于？

0.999… 和 1 之间，到底是什么关系？

新版是一部约 6 分 35 秒的 Manim 数学电影，共七幕，串起 1/3、有限小数、阿基里斯追龟与极限。先留下你心中的答案，再跟着连续的画面与中文讲解，看看那些看似熟悉的数字，为什么会让人犹豫。

[在线观影](https://1172100122.github.io/superintelligence-education-press/works/limits/) · [作品目录](https://1172100122.github.io/superintelligence-education-press/)

- 完整中文讲解与可开关的中文字幕

## AI 的证明 · 第一集：幻觉还是神谕？

一部约 11 分 48 秒的中文教育影片。跟随一份证明，从素数走到 Lean，看看推理为何可信，以及检查到底检查了什么。黑板与小稿纸上的线索，串起十二个章节。

[在线观影](https://1172100122.github.io/superintelligence-education-press/works/ai-proof-episode-1/) · [下载 MP4](https://1172100122.github.io/superintelligence-education-press/works/ai-proof-episode-1/episode01-v2-f790f5638a15.mp4) · [中文字幕](works/ai-proof-episode-1/episode01_zh.vtt)

支持章节跳转、重播与同步文字。研究图像和延伸阅读的来源见播放页；第三方图像的权利归原权利人。

本项目使用 Dots 的免费额度完成制作。就这次尝试而言，动画表现与 Claude 相比还有差距，不过胜在成本低。
